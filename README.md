# GSE107451 ML Classification

Machine learning classification using Drosophila brain RNA-seq data
from NCBI GEO accession GSE107451.

## Project workflow

1. Download and inspect the dataset
2. Clean and prepare the data
3. Create the ML classification dataset
4. Train and evaluate models
5. Generate results and figures

## Data source

NCBI GEO: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE107451
