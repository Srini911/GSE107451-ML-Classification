# GSE107451 ML Classification

Machine learning classification using Drosophila brain RNA-seq data from NCBI GEO accession GSE107451.

## Project workflow

1. Inspect the original GEO dataset
2. Clean and prepare the biological data
3. Create the ML classification dataset
4. Train and evaluate machine-learning models
5. Generate results and figures

## Data source

https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE107451
